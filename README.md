# Maths SEM-I Exam To-Do

A lightweight, mobile-friendly study checklist based on the supplied *Maths SEM-I: Exam To-Do* PDF. Tick topics as you finish them, search the syllabus, and ask the built-in study helper for a topic or a next-step suggestion.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## GitHub Pages

This app is static and works from the repository root. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The included GitHub Actions workflow also supports automatic Pages deployment after enabling Pages with GitHub Actions as the build source.

Checklist progress is saved in local browser storage and stays on that device/browser.
